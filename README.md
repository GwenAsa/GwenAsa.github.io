## About

Hi, I'm **Asa**. I build custom **Discord bots in Python** with slash commands, embeds, buttons and clean cog-based code. I come from a branding and graphic design background, so my bots are designed to look and feel good inside Discord, not only to work.

This repository is the source code of my portfolio website, a Discord-styled single-page site hosted on GitHub Pages.

**Live site:** https://gwenasa.github.io

## About this website

- Single `index.html`, pure HTML, CSS and JavaScript
- No framework, no build step, no backend
- Fully responsive, with keyboard focus styles and reduced-motion support
- Hosted on GitHub Pages

### Run it locally

```bash
git clone https://github.com/GwenAsa/GwenAsa.github.io.git
cd GwenAsa.github.io
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
